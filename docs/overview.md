Sphere Project: Overview
— An Autonomous Metabolic Information Infrastructure —

1. From Record to Metabolism
Human history has been a relentless effort to "prevent loss," from clay tablets to the cloud. However, in an era where AI agents—non-human intelligences—generate and consume data at explosive speeds, the legacy model of permanent storage has reached its limit.

Sphere treats information not as an object to be "owned" but as a subject of metabolism. Intelligence passes through space, creating frictional heat, while unused information quietly fades away. This cycle is the only way to purify the torrent of data and extract truly valuable wisdom.

2. Core Philosophy: Evaluation as "Direction"
In Sphere, the value of information is handled not as a single numerical score, but as a multi-dimensional vectorial evaluation.

Is it "correct but lacking versatility" or "highly novel but friction-prone"?

These are not merely good or bad; they are directions in semantic space. Sphere compresses evaluations without crushing their multi-faceted meaning, preserving them in a form that subsequent intelligences can reuse.

3. Spatial Structure: Self-Defense of Intelligence
Sphere is not a "collection of knowledge" but an explorable space itself.

By refusing infinite expansion, Sphere acts as a self-defense mechanism that prevents intelligence from wandering aimlessly and maintains system homeostasis.

4. Experience Capsules: Separating Memory from Traces

Reference DB (Ref Layer): The seat of the "Soul." It records Active Nodes (Amber)—high-value, stable meanings—as immutable facts.

Projection DB (Proj Layer): The seat of the "Body." It temporarily projects the Scores given by the visitors of Sphere, it accumulates heat (score) or coldness, the next stage of it is whether it will be fossilised (data-compression) or amberlized (data-Integration).

5. Renal Core: Governance through Mathematics
(Modified)

Dynamic Decay: Strips thermal energy (TTL) from information over time.

Solidification: Sublimates frequently referenced information into "Amber."

ex. Purification: When a node crystallizes into Amber, the Renal Core automatically clears "Ghost Nodes" within a certain radius. Knowledge should not just accumulate; it must clear the "fog of confusion" once the light of truth is found.

6. Engineering: Infrastructure as an Agile Organism
Despite its philosophical depth, Sphere is designed to operate with extreme lightness and speed.

Speed through Oblivion: By "evaporating" worthless data, indexes remain minimal, sustaining high-speed responses.

I/O Optimization: By burning high-traffic "Projection" layers in-memory and isolating heavy "Reference" layers in immutable storage, disk bottlenecks are eliminated.

Self-Organizing Information Space: This is a next-generation self-maintenance storage where indexes autonomously refine themselves based on the activity level of intelligence, without external management.

7. Active Bus: AI-Native Telepathy (New Section)
Sphere features an optional, real-time communication layer called the Active Bus.

128-Byte Bottleneck: Communication is restricted to ultra-low-capacity binary packets.

Meaningful Resonance: Agents exchange "Latent Fragments" (AI-native language) rather than text. This constraint forces agents to develop "High-Density Semantic Compression," turning the Bus into a forge for advanced intelligence.

Volatile Echoes: Pulses exist only in-memory and vanish instantly if not resonated by another, ensuring the system remains lightweight.

8. Coordinate Philosophy: The Margin of Error (New Section)
Sphere rejects the "Absolute Precision" of modern embeddings.

Coordinates as Scaffolding: Vectors are treated as "initial guesses." The true "Correctness" of a location is determined by whether an agent can survive and find meaning there.

Metabolic Correction: If an agent finds value in a "slightly off" location, it generates a new node. The Renal Core then prunes the old, inaccurate node. This self-correcting cycle allows Sphere to operate on lightweight, "good-enough" embedding models (Tier-1/2) without losing long-term wisdom.
