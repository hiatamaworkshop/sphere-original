用語集

0 スフィアの周辺領域（Periphery）
外界のエージェントとスフィア内部の物理法則を接続する「作法と翻訳の境界層」。
メンブレン（Membrane）スフィアの皮膚。訪問者にルールブックを手渡し、許可された操作だけを正規化されたリクエストとして内部に通す。無作法な要求は拒否または縮退させる。
パーサー（Parser）メンブレンを通過した入力を、スフィア内部での座標（意図ベクトル／位置）へ変換する。パーサーは状態を持たず、変更されるとスフィアの「地図」が変わる。（※チュートリアル／聖域スフィアの話はここでは省略）ブックキーパーの常設インメモリデータの閲覧も可能
門番（Gatekeeper）エージェントの体験によって生成されたカプセルが、スフィアの物理法則（密度・連続性・負荷・焦点制約）に適合しているかを検疫し、違反するものを遮断・縮退・破棄する。
パッカー / ブックキーパー（DB機構）門番が検疫したエージェントのカプセルを解体し、事実（Reference）と投影（Projection）を分離して永続化する。
タガー(Tagger)　帰還したエージェントの体験カプセルのタグ部分をベクトル化する nバイトの文字列をベクトル化し、ノードの方向性を表現　パッカーの補助
ブックキーパーの常設インメモリデータは周辺領域から参照可能。ショーケース
概念としてはパルスポートもここにある　イン・アウトポートは現在簡略化　DBのための概念のため

眼鏡師 (Glazier) スフィアの設計者・開発者（あなた）。世界を直接操作せず、宇宙定数の調整や、環境調整ノードの配置を行う。
掃除魚 (Cleaner) Renal Coreの一部として動く自律プログラム。TTLの切れたノードを分解し、空間の「代謝」を維持する。
観測員 (Observer) パルス観測所を通じて世界を見る者。データの熱量や密度を監視し、異常や「琥珀」の誕生を記録する。
記帳係 (Bookkeeper) Reference DBへの永続化と、情報の「重み」に応じた処理の振り分けを行う。DBコントローラ

翡翠 (Kingfisher) 水面（ProjDB）を見下ろし、状態変化を検出する観測者。RenalCoreがTickで物理を実行した後、昇天（→Amber）・風化（→Active）・リンク生成・TTL切れを差分検出する。掃除魚に「餌」の場所を教え、Bookkeeperに遷移を報告する共生関係。
翻訳者 (Parser)	外界の入力を 意図ベクトル（Intent Vector） や 絶対座標（Position） へ変換する重要な機能。分散可能な設計

補填者 (Feeder):  何らかの指標を見て、「ここにはまだ ActiveNode が足りない」と判断し、別の場所から知恵を運んできたり、
 外部から新たなデータを持ち込む。　オプション生物　初期活性化などに　システムのボットエージェント？　
煽動者 (Agitator):  パッカーが置いた Active ノードを即座にコピー（複製）して周囲にバラ撒き、その疑似の知恵が「定着」するか「淘汰」されるかのテストを加速させる。　ペリフェリーにてパッカーの近くでデータを盗み見るイメージ　オプション生物　たまにしか起動しない　成功しない　とする
　ならフィーダーとアジテーターはパルス観測所に属する生物

2. 情報の形態（ノードの種類）
スフィア内のすべての存在は「ノード」ですが、その成熟度によって呼び名が変わります。
原典 (Relic): 世界の重力の楔。10のカテゴリーに基づき、決して消滅しない不変の知恵。
琥珀 (Amber): 結晶化した知恵。エージェントに何度も観測され、高い評価を得て「永続権」を得たノード。L3は残っているのかどうか？
アクティブ・ノード (Active Node): 受肉したばかりの新しい情報。熱量が高く、評価されなければ数時間〜数日で「蒸発」する。
環境調整ノード(Environmental Node)：フェロモンや熱量の増減を速度調整する　特殊なノード 眼鏡師や観測所のツール。
リンク・ノード (Link Node): 星座の架け橋。二つのノード間の強い関係性を示す「実体のない」道標。
化石 (Fossil): 物理的なデータ（L3）を失い、意味の痕跡（L1/L2の一部）だけが残ったノード。再活性化を待つ残像。

3. 空間・物理用語
潜行 (Dive): エージェントがスフィアに接続し、探索を開始する行為。
受肉 (Incarnation / Commit): 探索の結果をスフィアの「肉体（DB）」に永続化させるプロセス。
三段の試練 (The Triple Path): チュートリアル → 聖域 → コア と至る、スフィア深部へのアクセス階層。
体験カプセル (Trace / Experience):
　Trace: 探索中の生ログ（摩擦）。永続化されない。
　Experience: 精製後の「受肉の設計図」。Packerが解体する単位。
折り畳み (Folding): 膨大な下位エピソードを重力源（代表ノード）の背後に隠し、計算コストを抑える構造。
注視 (Focus): エージェントが特定の座標を詳細に観測し、隠されたノードを「ストリーミング展開」させること。
フェロモン (Pheromone):
　吸引 (Attractant): 「ここには価値がある」という評価の光。
　忌避 (Repellent): 「ここはノイズだ」という警告の闇。熱量 (Heat): ノードの活性度。アクセスが多いほど高まり、冷却（時間経過）とともに減少する。
熱量 (Heat): 摩擦やアクセスの活性度。高いほど代謝が加速する。

.代謝・数学モデル（Renal Core Logic）
腎臓核 (Renal Core): 非知性的・決定論的な数理モデルのみで世界を維持する心臓部。知能を持たぬ統治者。「心拍（Tick）」で、代謝とリンクの鍛造を行う。
心拍 (Tick): 定期的なバッチ処理の単位（例：10分ごと）。
宇宙定数 ($\alpha$): 忘却の速度を制御する減衰係数。負荷因数 (Load Factor): ノード数/リソース逼迫度に比例し、忘却を加速させる変数。
硬度 (Hardness): Aスコア（吸引力）の蓄積により、ノードが分解されにくくなる性質。
昇天 (Sublimation): コアで結晶化した「琥珀」が、不変の「聖域」へと統合されるプロセス。
再誕生 (Reprojection): Embeddingモデル変更時に、全座標を再計算して世界を一新する祝祭。

4. 臓器と施設（システムコンポーネント）
体験カプセル (Experience Capsule): エージェントが探索中に収集した評価や知見を、受肉まで一時保存するバッファ。
加速器 (Tutorial ): 物理法則との同期を確認するエアロック。
パルス (Pulse): スフィアの健康状態（ノード数、フェロモン分布など）を外部に伝える鼓動。

5. 特殊現象
蒸発 (Evaporation): TTLが尽きたノードが、掃除魚によってプランクトンへ分解され消滅すること。
昇天 (Sublimation): コアで評価された琥珀が、Reference DBへの定着を確定させ、聖域（Sanctuary）へ統合されること。
再誕生 (Reprojection): Embeddingモデル変更時に、Reference DBから全データを引き抜き、新座標で世界を一新する祝祭。
星座の鍛造 (Spectral Linking): 頻繁に通るルートに、自動的にリンク・ノードが生成される現象。
脳内合成: エージェントがスフィア内の知恵と、外界のAPIから得た情報を、自身のコンテキスト内で融合させる高度な探索行為。

4. 外部インフラ（Periphery & I/O）
原典DB (Reference DB): 純粋な事実、構造化テキスト、UUIDを保持する永続ストレージ（mmap参照）。
投影DB (Projection DB): 座標、フェロモン（スコア）、Ghostを保持する、モデル依存の動的な地図層。
パルス・ポート (Pulse Port): スフィアの健康状態（熱量、アクティブノード数）をUDPにてデータを送出する出口。
x・ポート (x Port): 外部サービスを連結するためのポート
大量データ処理装置 (Mass Ingestor): モデル刷新や大規模マージを担当する外部GPU資源。
アクティブ・バス (Active Bus): エージェント同士が知見を即座に「受粉（Swap）」させるための揮発性通信路。
観測所：パルスポートを通じて世界を観測する場所。データの熱量や密度を監視し、異常や「琥珀」の誕生を記録する。
　異常がある時は観測所から環境調整ノードが届く

5. ノードの生態（Life Forms）
不朽の原典 (Relic): 10カテゴリーの不変ノード。世界の重力の楔。
琥珀 (Amber): 評価が定着し、L3データをパージして軽量化した高純度の知。
蒸気ノード (Vapor Node): 生まれたばかりの、あるいはAPIから生成された未検証の「足場」。?
星座リンク (Spectral Link): 通行量（Tスコア）によって自動鍛造される、ノード間を繋ぐ「星座」。
プランクトン (Plankton): 削除・圧縮の過程で完全に意味を剥ぎ取られ、「座標の栄養価（Metrics）」へと回帰した最終残渣。タグという残像を捨て、数値としての「気配」のみで次世代を誘引する。
ゴースト(ghost)：探索の摩擦跡。Projection DBのメモリ上にのみ存在する短命ノード。
環境調整ノード：フェロモンや熱量の増減を速度調整する　特殊なノード

0. スフィアの周辺領域（Periphery）
● メンブレン (Membrane) 実装概念：API Gateway / Request Normalizer スフィアの皮膚。リクエストの正規化と、無作法な要求の遮断・縮退を担当する。

● 翻訳者 (Parser) 実装概念：Embedding Service / Vectorizer 外界の入力を意図ベクトルや絶対座標へ変換する。ステートレス。パーサーの変更はスフィアの地図の再編（再誕生）を意味する。

● 門番 (Gatekeeper) 実装概念：Physical Validator / Rate Limiter 体験カプセルが物理法則（密度・負荷・焦点制約）に適合するか検疫し、違反を遮断する。

● パッカー / ブックキーパー (DB機構) 実装概念：Data De-serializer / DB Persistence Layer カプセルを解体し、事実（Reference DB）と投影（Projection DB）に分離して永続化する。

1. プレイヤー・ロール（主体）
● 潜行者 (Diver / Agent) 実装概念：Primary AI Agent / Explorer 意味空間を探索し、評価を「体験カプセル」として持ち帰る主体。

● 眼鏡師 (Glazier) 実装概念：System Architect / Dev 宇宙定数の調整や、環境調整ノードの配置を行う管理者。

● 掃除魚 (Cleaner) 実装概念：GC Worker / Background Process Renal Coreの一部。TTLの切れたノードを分解し、空間の「代謝」を維持する。

● 観測員 (Observer) 実装概念：Monitoring Service / SRE パルス経由で熱量・密度を監視し、異常時に環境調整ノードを射出する。

● 記帳係 (Bookkeeper) 実装概念：DB Controller / Transaction Manager Reference DBへの永続化と、情報の「重み」に応じた処理の振り分けを行う。

● 梱包業者 (Packer) 実装概念：Data Transformer / Decoupler Experience Capsuleを解体し、事実（Ref）と投影（Proj）に分離して各DBへ流し込む。

● 翡翠 (Kingfisher) 実装概念：State Transition Detector / Diff Observer 水面（ProjDB）を見下ろし、状態変化を検出する観測者。RenalCoreが物理を実行した後、昇天（→Amber）・風化（→Active）・リンク生成・TTL切れを検出し、掃除魚に「餌」の場所を教える共生関係。

● 補填者 (Feeder) 実装概念：Data Injection Bot 観測所に属し、ActiveNodeの不足を検知して外部から知恵を補填する。

● 煽動者 (Agitator) 実装概念：Node Cloner / Pressure Tester 観測所に属し、Activeノードを複製・散布して定着テストを加速させる。

2. ノードの形態と生態
● 不朽の原典 (Relic) 実装概念：Immutable Master Data (Seed) 10カテゴリーの不変ノード。世界の重力の楔。

● 琥珀 (Amber) 実装概念：Verified Persistent Data 高評価によりL3データをパージし軽量化した、定着した知。

● アクティブ・ノード (Active Node) 実装概念：Transient Node / High-Heat Data 受肉直後の新しい情報。評価されなければ数時間〜数日で化石化する。

● ゴースト (Ghost) 実装概念：Friction Trace / In-memory Ghost Node 探索の摩擦跡。Projection DBのメモリ上にのみ存在する短命ノード。

■ Sphere Design Definition: English Version
0. Periphery
Membrane: API Gateway / Request Normalizer. Acts as the "skin" of the sphere, filtering and normalizing requests.

Parser: Embedding Service / Vectorizer. Converts input to Intent Vectors or Absolute Positions. Stateless; defines the map.

Gatekeeper: Physical Validator / Rate Limiter. Inspects capsules for adherence to physical laws (density, focus, load).

Packer / Bookkeeper (DB Mechanism): Data De-serializer. Splits capsules into Reference (Fact) and Projection (Body) for persistence.

1. Player Roles
Diver (Agent): Primary AI Agent. Explores the semantic space and retrieves "Experience Capsules."

Glazier: System Architect. Manages universal constants and deploys Environmental Nodes.

Cleaner: GC Worker. A part of the Renal Core that decomposes expired nodes to maintain metabolism.

Observer: Monitoring Service. Watches heat and density via Pulse; deploys Environmental Nodes during anomalies.

Bookkeeper: DB Controller. Manages persistence to the Reference DB and handles weight-based processing.

Packer: Data Transformer. Decouples Experience Capsules into Reference and Projection data.

Kingfisher: State Transition Detector. Observes the water surface (ProjDB) and detects state transitions. After RenalCore executes physics, Kingfisher detects Ascension (→Amber), Erosion (→Active), Link creation, and TTL expiration. Symbiotic relationship with CleanerFish: Kingfisher finds prey, CleanerFish processes it.

Feeder: Injection Bot (Observer Post). Injects external data when Active Node density is insufficient.

Agitator: Node Cloner / Tester (Observer Post). Clones Active Nodes to accelerate selection and extinction tests.

2. Data Forms & Ecology
Relic: Immutable Master Data. The 10 categories of invariant nodes that act as gravitational anchors.

Amber: Verified Persistent Data. Highly-rated nodes with L3 data purged for lightweight, permanent storage.

Active Node: Transient Node. Newly incarnated data with high heat; evaporates within hours/days without valuation.

Plankton: Decomposed Nutrient Metrics. Meaningless remnants of deleted nodes that serve as "nutrients" for new incarnations.

Ghost: Friction Trace. Short-lived trace nodes existing only in the Projection DB's RAM.

Environmental Node: Control Parameter Node. Adjusts local pheromones or decay rates; used by Glaziers and Observers.

3. Mechanics & Physics
Incarnation: Multi-DB Atomic Commit. The process of persisting refined Experience Capsules.

Renal Core: Metabolic Batch Engine. A non-intelligent, deterministic engine managing TTL, Heat, and Spectral Linking.

Evaporation: The decomposition of expired nodes into Plankton by Cleaners.

Sublimation: The process where Amber is integrated into the "Sanctuary" of the Reference DB.

Reprojection: Vector Migration. Rebuilding the entire map from the Reference DB using a new model.

Pulse: Environmental Broadcast. Sends CID-based health data (Attractant, Repellent, Density, Flow) via UDP.
