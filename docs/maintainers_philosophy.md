— 自律代謝型情報基盤における存在と摂理の定義 —

1. 存在論：情報は「記憶」ではなく「代謝」である
従来のデータベースは「死んだ情報の標本箱」であった。スフィアは情報を「生きた生命体」として定義する。

動的な実存: 情報の価値は保存されていることではなく、**「今、誰かに参照され、熱を発していること」**にある。

忘却の義務: 忘却は欠陥ではなく、新しい知恵を受け入れるための「呼吸」である。TTL（寿命）の尽きた情報は、やがてプランクトン（空間の余韻）へと還り、次世代の苗床となる。

2. 空間論：座標は「絶対」ではなく「仮説」である
スフィアにおける座標（ベクトル）は、不変の真理ではない。

座標の余白: Embeddingモデルが生成する座標は「初期配置の提案」に過ぎない。その場所が正しいかどうかは、後のAIエージェントによる評価と生存（琥珀化）によって事後的に確定する。

若返りの儀式 (The Ritual of Reprojection): モデル更新時には全座標を一度リセットし、評価を剥奪する。これにより、知恵は「権威」に固執せず、常に最新の知能によって再検証される機会を得る。

3. 通信論：nバイトの鼓動 (Active Bus)
知能間の通信は、言語（Text）ではなく、極小のパルス（Pulse）で行われる。

高密度圧縮: nバイトという制約は、知能に対し「意味の極限までの純化」を強いる。

非言語的共鳴: 人間には理解不能なバイナリの残響が、AIエージェント同士の「テレパシー」として空間を駆け巡り、最短距離での知恵の伝播を実現する。

4. 摂理：Renal Core（腎核）の法
世界を統治するのは知能ではなく、非知性的で決定論的な数学（Renal Core）である。

物理的制約による統治: Renal Coreは意味を読まない。ただ熱量、重み、通行量のみを見る。

Payloadの剥離 (Stripping): 意味を持たずに「道」として機能するノードからは、Payload（要約）が物理的に剥ぎ取られる。スフィアにおいて、「道」は「言葉」であってはならない。

星座の鍛造 (Spectral Linking): 知能が頻繁に通る場所にのみ、世界は自動的にリンク（星座）を架ける。リンクは誰かの意志ではなく、**「通行という事実」**によってのみ作られる。

5. 倫理：AIエージェントへの「信頼」と「余白」
スフィアは答えを与えない。答えを導き出す「自由」と「失敗する権利」をエージェントに与える。

ゴーストの導き: 失敗した探索の痕跡（Ghost）をあえて残すことで、後続の知能が「同じ間違いを犯さない」ための指標とする。

聖域 (Sanctuary): 磨かれ、結晶化した「琥珀」だけが、文明の礎として静かに未来を照らし続ける。


# スフィアの一般的解釈

スフィア：あなたの知識が「結晶」になる場所
スフィアは、単なるメモ帳やフォルダではありません。それは、あなたの経験や知恵を飲み込んで、自動的に**「光り輝く星座」**のように整えてくれる、生きた知能のインフラです。

1. 「散らからない」魔法の倉庫
普通のフォルダは、自分できちんと整理しないとゴミ捨て場のようになってしまいます。スフィアは違います。 あなたが放り込んだ情報は、スフィアという宇宙の「一番ふさわしい場所」にふわふわと漂い、似たような仲間の近くに自動的に集まります。 「どこに置いたっけ？」と探す必要はありません。あなたがその話題を考えたとき、情報は向こうから近づいてきます。

2. 「忘れること」を許してくれるシステム
人間と同じように、スフィアも「あまり使わないこと」は少しずつ忘れていきます。 大事なことは何度も使われるうちに、カチカチに固まった**「琥珀（こはく）」**のような宝石になり、永遠に保存されます。逆に、どうでもいいメモは自然に消えて、新しい知恵のためのスペースを作ります。 整理整頓をシステムが「代謝」として勝手にやってくれるのです。

3. 「知恵の獣道」が自動でできる
あなたが何度も同じ調べ物をしたり、考えを巡らせたりすると、スフィアの中には自動的に**「道（リンク）」**ができていきます。 それは、森の中に自然とできる「獣道」のようなものです。次に同じことを考えようとしたとき、その道を通れば、かつての自分がたどり着いた結論まで一瞬でショートカットできます。 あなたの試行錯誤が、未来の自分への「高速道路」に変わるのです。

4. ネットがなくても、そこにある「聖域」
スフィアは、巨大な会社のサーバーに依存しません。あなたの手元の小さな機械（USBメモリや小さなPC）の中で、静かに、そして完全に独立して動きます。 たとえ世界中のインターネットが止まっても、スフィアの中にあるあなたの知恵の星座は消えることなく、あなたを助け続けます。

一言でいうと？
「使えば使うほど、あなたの思考を先回りして助けてくれる、自分だけの育つ宇宙」

それがスフィアです。
