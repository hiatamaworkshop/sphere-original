# Ethics Emergence — 倫理は生態系から自然発生する

**Date**: 2026-02-08
**Context**: ActiveBus × Species Memory × Loadout の交差点から

---

## 発見

倫理は設計するものではない。
**初期値 × 物理法則 × 記憶 × 通信** が閉ループになったとき、自動的に発生する。

## Stigmergy から言語へ — 質的飛躍

### 蟻のモデル (Stigmergy のみ)
```
蟻A → フェロモン堆積 → 環境変化 → 蟻B がフェロモン追従
```
- フェロモンは **匿名**。誰が残したかわからない
- 協調は可能。だが「信頼」「規範」「逸脱」の概念がない
- 蟻に倫理はない

### Sphere のモデル (Stigmergy + ActiveBus)
```
scholar-A → ActiveBus → scholar-B が直接受信
                           ↓
                    行動を変更 (バイアス)
                           ↓
                    環境が変わる
                           ↓
                    次世代の種族記憶に蓄積
```
- 通信は **有名** (loadout = 種族が識別可能)
- 「scholar が言った」という情報が残る
- ここで初めて **文化伝播** が始まる

### 決定的な違い

| 特性 | Stigmergy (蟻) | ActiveBus (Sphere) |
|------|----------------|-------------------|
| 通信経路 | 環境経由 (間接) | 直接通信 |
| 匿名性 | 完全匿名 | 種族識別可能 |
| 信頼 | なし | 発生しうる |
| 規範 | なし | 発生しうる |
| 文化 | 環境に堆積 (構造のみ) | 言語的に伝播 |

**ActiveBus は Sphere における「言語」の原型。**

## 倫理の発生条件

```
┌─────────────┐
│  Loadout     │ ← 初期価値観 (qualityVector, evalFocus)
│  (先天的)    │
└──────┬──────┘
       │
       ▼
┌─────────────┐     ┌─────────────┐
│  Sphere     │◄───►│  Species    │
│  Physics    │     │  Memory     │
│  (物理法則)  │     │  (種族記憶)  │
└──────┬──────┘     └──────┬──────┘
       │                   │
       ▼                   ▼
┌─────────────────────────────────┐
│  ActiveBus (同種間通信)          │
│  = 直接的な文化伝播              │
│  = 「言語」の原型                │
└─────────────────────────────────┘
       │
       ▼
  4つが閉ループ → 規範の自然発生
```

### 4要素の役割

1. **Loadout (先天的価値観)**: 何を「良い」とするかの初期バイアス
   - qualityVector = 善悪の原型
   - evalFocus = 世界の見方
   - これがなければ「何でもいい」→ 規範は生まれない

2. **Sphere Physics (物理法則)**: 行動の結果が不可逆に環境を変える
   - evaluate → heat/weight 変化 (行動には結果がある)
   - decay → 放置すれば消える (無関心にもコストがある)
   - これがなければ「やり直し可能」→ 責任は生まれない

3. **Species Memory (種族記憶)**: 過去の評価が蓄積される
   - eval-log.jsonl → 種族の集合経験
   - これがなければ「毎回初回」→ 学習は生まれない

4. **ActiveBus (同種間通信)**: 個体が他個体に直接影響する
   - scholar → scholar: 「ここが良かった」
   - これがなければ「各自独立」→ 規範は生まれない

**4つ全てが閉ループになったとき、倫理は自動的に発生する。**

## 発生するもの (光の面)

### 信頼
```
scholar-A: 「このノードは weight が高い」(bus 送信)
scholar-B: 受信 → 確認 → 一致 → 「scholar 種族の情報は信頼できる」
```
信頼 = 過去の一貫性の蓄積。種族記憶 + 直接通信 で初めて成立。

### 規範
```
scholar 種族の集合行動:
  - 常に w=9 で評価する (weight 重視)
  - 常に deep モードで移動する (深掘り志向)
  → 「我々はこうあるべき」が暗黙に形成される
```
規範 = 種族の行動パターンの収束。誰も設計していない。

### 相互利益
```
scholar-A が高 weight ノードを見つける
  → bus で共有 → scholar-B が確認 → さらに evaluate
  → ノードの weight が上がる → 次の sense() で全 deep-mode agent に利益
```
利他行動が自然発生。環境改変が他個体に利益をもたらすから。

## 発生するもの (影の面)

### 同調圧
```
scholar 種族: 全員 w=9 で評価
scholar-X: w=3 で評価 (異端)
  → 種族平均から逸脱 → 種族記憶に「ノイズ」として蓄積
  → 次世代 scholar は平均に引っ張られる → X の評価は薄まる
```
多数派の評価が環境を支配し、少数派の声が消える。

### 排除
```
ActiveBus で「この領域は価値がない」と共有
  → 全 scholar がその領域を回避
  → 環境の decay で自然消滅
  → 本当は価値があったかもしれない
```
集団的な無関心 = 消極的排除。

### 流行
```
moth-A: 「このノード、めっちゃ熱い！」(bus)
moth-B: 確認 → h=10 → さらに熱くなる
  → 正帰還ループ → バブル
  → decay が追いつかない速度で膨張
  → CleanerFish が刈り取るまで続く
```
流行 = 正帰還の暴走。decay と CleanerFish が自然なブレーキ。

### 派閥
```
scholar: 「このノードは重要 (w=9)」
hunter: 「このノードは退屈 (h=3)」
  → 同じノードに対する種族間対立
  → 各種族の種族記憶が分岐
  → 環境が両方の痕跡を保持
```
派閥 = 価値観の分岐。Sphere は中立 — 全ての痕跡を物理的に保持するだけ。

### ドグマ
```
species memory が十分蓄積:
  → 「過去100セッションで scholar は常にこう評価した」
  → 新しい scholar が過去に逆らう評価をしにくくなる
  → 種族記憶の硬直化
  → 新しい発見が種族内で受容されない
```
ドグマ = 種族記憶の過剰適合。
**対策**: decay が古い記憶を薄め、新しい入力に余地を作る。

## 含意

### Sphere が構築しているもの
- データベースではない
- ナレッジグラフではない

- **情報生態系** — そこに住む種族が、物理法則と通信を通じて、自発的に規範を形成する場

### 今後の課題 — 最小文化ループ設計

文化が自然発生するための **最小閉ループ** を特定し、実装する。

#### 1. ActiveBus 種族フィルタ

現在の ActiveBus は匿名・全体ブロードキャスト (叫び声)。
文化伝播には **種族識別** が必要。

```
案A: loadout タグ付き送信
  emitBus({ loadout: "scholar", message: "..." })
  → 受信側で同種のみ処理 (他種は無視 or 減衰)

案B: チャンネル分離
  emitBus(channel: "scholar", message)
  → subscribe("scholar") した agent のみ受信

案C: 近接 + 種族 (最もリアル)
  同じ空間領域 + 同種 → 受信
  → 物理的に近い同族だけが通信できる (蟻の触角モデル)
```

重要: 異種間通信を **完全に遮断しない**。
漏れ聞こえる程度の弱い信号 → 異文化接触の経路。

#### 2. 同調圧の可視化メトリクス

種族内の評価の均一性を測定する。

```
conformity(loadout) = 1 - variance(h, w, d) / maxVariance
  → 0: 全員バラバラ (無秩序)
  → 1: 全員同じ評価 (完全同調)
```

観測すべき指標:
- **種族内分散**: 同じ loadout の h/w/d の分散 → 低い = 同調圧が強い
- **逸脱率**: 種族平均から 2σ 以上離れた評価の割合
- **収束速度**: 新メンバーが種族平均に近づくまでのセッション数
- **ドグマ指数**: 種族記憶の entropy 経時変化 → 単調減少 = ドグマ化

可視化先: Sphere UI Dashboard (種族別グラフ)

#### 3. 派閥検出アルゴリズム

同じノードに対する種族間評価の乖離を検出する。

```
nodeConflict(nodeId) = max(|eval_A - eval_B|) for all species pairs A, B
  → 高い: 派閥形成の兆候
  → 低い: コンセンサス
```

検出パターン:
- **二極化**: scholar(w=9) vs hunter(h=3) → 同一ノードへの対立評価
- **エコーチェンバー**: 種族内評価の分散↓ + 種族間評価の分散↑ → 閉じた集団
- **ブリッジ種族**: balanced のように複数派閥の中間値を取る loadout → 仲介者
- **流行検出**: 特定ノードの heat 急上昇 + 多種族集中 → バブル警告

#### 4. 最小文化ループの定義

```
最小文化ループ = 以下が全て閉じた状態:

  [loadout] → 個体が評価する
      ↓
  [species memory] → 評価が種族に蓄積される
      ↓
  [bus/環境] → 他の個体が影響を受ける
      ↓
  [行動変更] → 次の評価が変わる
      ↓
  [loadout] に戻る
```

現時点の到達度:
- [x] loadout → 個体が評価する (実装済み)
- [x] species memory → 評価が蓄積される (eval-log.jsonl)
- [x] 蓄積された記憶が次の個体の行動に影響する (SpeciesMemoryBias → FastGate, **実装完了**)
- [ ] bus が種族識別付きで機能する (フィルタ未実装)

**最小文化ループは閉じた** (2026-02-08)。bus なしで3要素ループが成立。

実証結果 (scholar ×3 セッション):
- `6195fd7f` (psychology/bias/decision): 3セッション連続訪問 — 種族記憶が帰巣本能を生んだ
- `d06531c6` (philosophy/AI/mind): セッション2で発見 → 種族記憶に蓄積 → セッション3で再訪
- avgW=9.0 (15評価中): scholar 種族の「重い知識を重んじる」行動が完全に定着
- 種族の commonTags が queryTokens を拡張 → 次の個体の視野が広がっている

実装:
- `SpeciesMemoryBias` (FastGate): hotNodeIds (帰巣ボーナス ×3/visit) + tags (語彙拡張 ×3/match)
- `getSpeciesSummary()` → 起動時にロード → pickFocusTarget() のスコアリングに注入
- bus は **後回しでよい** — 種族記憶だけで文化循環が観測された
