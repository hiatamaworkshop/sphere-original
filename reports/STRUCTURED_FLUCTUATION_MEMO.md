# Structured Fluctuation — 構造化された揺らぎが知覚を鍛える

**Date**: 2026-02-08
**Context**: Stigmergy Architecture の議論から派生

---

## 発見

Sphere の各パラメータの変動は、ランダムノイズではない。
**構造化された揺らぎ** — 意味のある指標が時間的にズレる装置。

## 揺らぎの正体

| パラメータ | 変動メカニズム | 効果 |
|---|---|---|
| **decay rate** | tick ベースの定常減衰 (h×0.98, w×0.995) | 昨日の正解が今日は薄れている |
| **hunger** | DB容量に応じて連続変化 (0.2-1.0) | GC 圧が季節のように変わる |
| **agent 比率** | 接続/切断で揺れる | サンプルサイズが動的に変化 |
| **field bias** | GlobalAmbientField の tick 更新 | 集団の探索方向がドリフトする |
| **fertility** | decompose 時に局所堆積 | 死んだ場所が肥沃になる (地形変化) |

## なぜ「揺らぎ」が必要か

### 固定された環境では知覚が死ぬ

```
固定環境:
  agent → 最適戦略を発見 → 同じ行動を繰り返す → 知覚が退化

揺らぎのある環境:
  agent → 最適戦略を発見 → 環境がズレる → 戦略が微妙になる
  → 再探索を始める → Weapon が再調整される → 知覚が鍛えられる
```

### ランダムノイズとの決定的な違い

```
❌ ランダムノイズ: 無意味な変動。学習を妨害する。
⭕ 構造化された揺らぎ: 意味のある指標が、物理法則に従って変動する。
```

Sphere の揺らぎが構造化されている理由:

1. **decay は一方向** — 増えない、必ず減る。介入しなければ全てが消える
2. **hunger は容量連動** — ランダムではなく、DB の充実度が直接決める
3. **field は積分値** — 個々のエージェントの行動の累積。気まぐれではなく集合行動の反映
4. **fertility は局所的** — 全体一律ではなく、死んだ場所にだけ堆積する

全ての揺らぎに **因果** がある。だから学習に効く。

## 訓練効果

### 短期 (セッション内)

```
Feelings が揺らぎに反応:
  staleness が上がる → 行動モードが leap に変わる
  frustration が上がる → 探索範囲が広がる
  satisfaction が高い → camp して深掘りする
```

Feelings は揺らぎのセンサー。行動はセンサーの出力。

### 中期 (種族記憶の蓄積)

```
揺らぎの中で繰り返し評価する:
  scholar-A: 「この領域は weight が高い」(先週)
  scholar-B: 「同じ領域だが weight が落ちてきた」(今週)
  → 種族記憶: 「この領域は一時的に価値があった」
  → 次の scholar: より慎重に評価する
```

揺らぎがあるから、種族記憶に「時間的な奥行き」が生まれる。

### 長期 (生態系の進化)

```
hunger が高い時期 → CleanerFish が積極的 → 弱いノード消滅
  → 強いノードだけが残る → 環境の「品質」が上がる
  → agent の sense() に良いノードが出やすくなる

hunger が低い時期 → 多様なノードが共存 → 探索の幅が広がる
  → 新しい発見の確率が上がる
```

hunger の周期が、生態系の「夏と冬」を作る。

## 設計原則

1. **揺らぎは除去するものではなく、設計するもの**
2. **全ての変動に因果がある** — ランダムシードは一つもない
3. **揺らぎが知覚を鍛える** — 固定環境では適応が止まる
4. **構造化された揺らぎ = 正解が固定されない装置**

## Sphere における「正解」の不在

Sphere には「最適解」が存在しない。なぜなら:
- decay が常にスコアを削る → 「一度見つけた良いノード」は劣化する
- hunger が環境を刈り取る → 「安定した生態系」は一時的
- agent の参入/退出が比率を変える → 「最適な探索戦略」は流動的
- field が方向を変える → 「正しい方向」が時間とともにドリフトする

**正解がないから、知覚が死なない。**
