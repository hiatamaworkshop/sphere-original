**目的:** 同じ Amber ペアによる重複リンク生成の防止 + リンク消滅後の再生成許可

**実装内容:**

| コンポーネント | 変更 | ファイル |
|---------------|------|----------|
| Arbiter | `linkedPairs: Set<string>` 追加 | `arbiter.ts:250` |
| Arbiter | `registerLinkedPair()` / `unregisterLinkedPair()` | `arbiter.ts:1060-1097` |
| Arbiter | `processCoOccurrence()` で linkedPairs スキップ | `arbiter.ts:953` |
| Bookkeeper | `setArbiter()` 遅延バインディング | `bookkeeper.ts:38-45` |
| Bookkeeper | `ingestLinkNode()` で凍結 | `bookkeeper.ts:166-172` |
| Bookkeeper | `applyDecomposition()` で解除 | `bookkeeper.ts:393-404` |
| index.ts | `bookkeeper.setArbiter(arbiter)` 配線 | `index.ts:292` |
| index.ts | 再起動時 linkedPairs 復元 | `index.ts:294-310` |

**動作フロー:**

```
[リンク生成] → registerLinkedPair() → co-occurrence 蓄積停止
[化石化]     → linkedPairs 維持（残骸存在）
[分解]       → unregisterLinkedPair() → co-occurrence 蓄積再開
[再起動]     → 既存 link/fossil の linkMeta から復元
```
