## 結論

### 種族性: 完全消失

smollm2:360m (360M) は evalFocus の指示を完全無視している。全種族が**完全に同一**のスコアパターン (h=8.0, w=7.0, d=4.0) を返す。

- **moth** の evalFocus: "How HOT is this? Only heat matters" → **h=8.0** (wanderer/hermit と同じ)
- **hermit** の evalFocus: "Ignore popularity... Weight and low decay matter" → **w=7.0** (wanderer/moth と同じ)
- **wanderer** の evalFocus: balanced → h=8.0, w=7.0, d=4.0

**種族性は完全に存在しない**。

### スコア範囲: 固定値スタンプ

360M は **全評価で h=8, w=7, d=4** を返す。分散ゼロ (stdH=0.0, stdW=0.0, stdD=0.0)。

qwen2.5:0.5b (0.5B) には僅かな分散があったが (stdH=2.3, stdW=1.9)、360M は **より硬直的**。

### スコア分布: 完全単一値

全 87 評価が h=8, w=7, d=4 の組み合わせ。
他の値は一切出現しない。

→ **LLM がコンテンツを読まず、定型値を返している** = 壊れた温度計 (常に 25°C を表示)

### Bus 通信: 可能だが無意味

h=8 固定のため、ActiveBus emit は発生する (wanderer: 30E, moth: 30E, hermit: 25E)。

しかし、**全エージェントが同じ値を emit** するため、Bus 通信に情報価値がない。
種族性がないため、Bus での種族差別化も不可能。

### 速度: 異常に高速

13-17s/session は phi3:mini (60s) の **75%高速**、qwen2.5:0.5b (33s) の **55%高速**。

**推論が速すぎる = コンテンツを読んでいない証拠**。
evalFocus を理解せず、即座に固定値を返しているため速い。

| Bus 通信 | 可能 | 可能だが無意味 | **FAIL** |

**smollm2:360m は Sphere の感覚器官として完全に不適格。**

全モデル中で**最悪の結果** — qwen2.5:0.5b (0.5B) より悪化。
種族差が完全に消失し、evalFocus を完全無視している。
